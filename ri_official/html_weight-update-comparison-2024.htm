Comparison of 2024 CPI data using new weights and previous weights

Table 1 compares the index values for January 2024 using the “new” weights (the official indexes based on the 2022 expenditure data) with the “old” weights (what the index values and percentages would be had the previous weights from 2021 remained in place). Table 2 shows the same comparison, but for 1-month not seasonally adjusted percent changes. Tables 3 and 4 offer similar data, but for March 2024 index values and 3-month not seasonally adjusted percent changes. Tables 5 and 6 offer similar data, but for June 2024 index values and 6-month not seasonally adjusted percent changes.

For item strata (for example, full service meals and snacks), difference in index movements from the different weights result from differences in the geographic weights. For aggregate indexes (for example, food at home), differences may result from the differing weights of the subcomponents of the aggregate.
